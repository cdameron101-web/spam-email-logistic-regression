# Spam Email Detection — Logistic Regression

## Overview
A Blacksheep Labs machine learning practice project that uses Python and Scikit-learn to classify emails as spam or not spam.

## Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab

## Project Workflow
1. Create and explore a synthetic email dataset.
2. Analyze summary statistics, correlations, and outliers.
3. Split the data into training and testing sets.
4. Train a logistic regression classifier.
5. Predict spam labels and probabilities.
6. Evaluate the model using a confusion matrix, accuracy, precision, recall, and F1-score.

## Dataset
This project uses 10 synthetic emails created for educational purposes.

## Limitations
The model is a learning prototype, not a production-ready spam filter. The test set contains only two emails, so its evaluation results cannot establish real-world reliability.
